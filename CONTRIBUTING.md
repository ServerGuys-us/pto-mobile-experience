# Changing the ptomobile.com website

Anyone can suggest a change. ServerGuys reviews every change before it goes live.

## Quick edit in the browser

1. Open the file you want to change on GitHub (for example `pricing.html` or `index.html`).
2. Click the pencil icon, make your edit, then click **Commit changes...** and choose
   **Propose changes**. GitHub copies the site to your account and opens a pull request.
3. Describe what you changed and why, then click **Create pull request**.
4. ServerGuys reviews it. Once it is approved and merged, the site updates within a few minutes.
